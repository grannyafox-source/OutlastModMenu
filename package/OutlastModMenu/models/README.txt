Model packs
===========

Put model pack .ini files here. Each one lists which character model
(skeletal mesh) replaces which character. See EXAMPLE_model_pack.ini.txt.

The models themselves are cooked Unreal Engine 3 packages (.upk). Install them
with the Mod Loader (OutlastModMenu\mods) so Outlast can load them.

You can also swap models without a pack: in the menu open Character > Model
swapper, pick who to change and choose any model that is currently loaded
(other characters, patients, Father Martin...).

Full details: docs\MODDING.md
