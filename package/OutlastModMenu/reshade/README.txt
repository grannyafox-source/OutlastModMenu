ReShade presets
===============

Presets in this folder can be copied next to the game with
Mod Loader > ReShade > "Install the mod's ReShade presets" and then selected
from the same page (or from ReShade's own menu).

  OMM_Clarity.ini         sharper image and slightly richer colour
  OMM_BrighterNights.ini  lifts dark areas a little, mild contrast curve

They use ReShade's standard effects (LumaSharpen, Vibrance, Levels, Curves):
tick "Standard effects" when installing ReShade.

You can put your own preset .ini files here too.
